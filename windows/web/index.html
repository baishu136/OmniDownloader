使用说明
OmniDownloader 全平台多媒体下载利器

极速上手三步法

  1. 复制链接：在哔哩哔哩、抖音、快手、小红书、TikTok、YouTube 等平台复制分享口令或网页地址。
  2. 一键解析：点击【粘贴剪贴板】或粘贴后点击【立即解析】。
  3. 选择格式下载：在底部弹窗选择音画合流、纯画面、音频或动图，开始下载。

解锁 B站 4K / 1080P60（SESSDATA）

  1. 在浏览器打开 bilibili.com 并登录账号；
  2. 按 F12，进入 Application → Cookies → https://www.bilibili.com；
  3. 找到 SESSDATA 并复制其值，在【设置 → 账号】中粘贴并保存。

極速上手三步驟

  1. 複製連結：於 Bilibili、抖音、快手、小紅書、TikTok、YouTube 等平台複製分享口令或網址。
  2. 一鍵解析：點選【貼上剪貼簿】後點擊【立即解析】。
  3. 選擇格式下載：選擇音畫合流、純畫面、音訊或動圖後下載。

解鎖 B站 4K / 1080P60（SESSDATA）

  1. 開啟 bilibili.com 並登入帳號；
  2. 按 F12 → Application → Cookies → https://www.bilibili.com 複製 SESSDATA 貼到【設定 → 帳號】。

Quick Start

  1. Copy the URL from Bilibili, Douyin, TikTok, YouTube, Xiaohongshu, Kuaishou or X.
  2. Analyze: click Paste Clipboard or paste a link and tap Analyze.
  3. Download: select Video, Mute, Audio, or GIF in the format sheet.

Unlock Bilibili 4K / 1080P60

  1. Log in to bilibili.com in your browser, open DevTools → Application → Cookies, copy SESSDATA, and paste it in Settings → Accounts.

クイックスタート

  1. URLをコピー：Bilibili、TikTok、YouTube、小紅書などから動画URLをコピーします。
  2. 解析開始：リンクを貼り付けて【解析開始】を押します。
  3. ダウンロード：動画・映像のみ・音声・GIF を選んでダウンロードします。

Bilibili 4K / 1080P60 解放

  1. bilibili.com にログインし、F12 → Application → Cookies から SESSDATA をコピーして設定 → アカウントに貼り付けて保存します。
