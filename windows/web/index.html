极速上手三步法

  1. 复制链接：在哔哩哔哩、抖音、快手、小红书、TikTok、YouTube 等平台复制分享口令或网页地址。
  2. 一键解析：回到本页面，点击【粘贴】按钮后轻触【解析】（或直接在输入框敲回车）。
  3. 选择格式下载：自主选择音画合流 (MP4)、纯视频画面、提取 MP3/M4A/FLAC 无损音频或 GIF 动图，点击开始下载。

核心特色与导出模式

🎬 音画合流 (MP4) 支持 4K、1080P60、1080P、720P。底层采用独立内置 FFmpeg 纯硬件级毫秒无损合成音视频流。
🔇 纯视频画面 自动剥离背景音轨，生成无声纯净视频，非常适合二创、混剪或鬼畜素材提取。
🎵 提取音频 直接抓取最高品质音频轨，支持转码为 MP3 (320kbps)、M4A、FLAC 无损或 OPUS。
🖼️ 动态图 (GIF) / 高清封面 双通道调色板算法生成高画质免播放器预览动图，或一键保存原始超清视频封面图。

解锁 B站 4K / 1080P60 高清画质 (SESSDATA 获取方法)

B站官方接口对未登录游客限制最高仅下发 480P。配置大会员账户的 SESSDATA 即可免费解锁 4K、1080P60 帧极清画质：

  1. 在电脑浏览器打开 bilibili.com 并登录您的账号；
  2. 在页面任意位置按键盘 F12 打开开发者工具，切换到【Application / 存储 / 应用程序】标签；
  3. 在左侧展开【Cookies】-> 点击 https://www.bilibili.com；
  4. 在列表中找到名为 SESSDATA 的项，双击复制它的 Value 值；
  5. 点击本网页顶部的【系统设置】-> 粘贴到【B站登录凭证】输入框中，点击【保存配置】即可立即生效！

桌面独立版与网页版说明

  • 桌面独立客户端 (Desktop App)：拥有独立原生窗口，基于微软 Edge WebView2 启动，关闭窗口即安全退出。
  • 网页纯后台版 (Web App)：静默常驻右下角任务栏托盘，内存开销极小。在设置中开启“浏览器原生接管下载”后，还可让手机/平板在同一局域网通过浏览器访问下载。

  2. 一鍵解析：回到本頁面，點選【貼上】後點擊【解析】（或於輸入框直接按 Enter）。
  3. 選擇格式下載：依需求挑選音畫合流 (MP4)、純視訊畫面、提取 MP3/M4A/FLAC 無損音訊或動圖，即可極速下載。

解鎖 B站 4K / 1080P60 超高畫質 (SESSDATA 獲取方式)

  1. 電腦瀏覽器開啟 bilibili.com 並登入帳號；
  2. 按 F12 開啟開發者工具，切換至【Application / 儲存】標籤；
  3. 展開【Cookies】-> 點擊 https://www.bilibili.com；
  4. 於清單中找到 SESSDATA，複製其 Value 數值；
  5. 至本網頁【系統設定】貼上並儲存，即可永久暢享 4K/1080P60 畫質！

How to Unlock Bilibili 4K & 1080P60 (SESSDATA Setup)

Unregistered guests are restricted to 480P by Bilibili. Configure your SESSDATA cookie to unlock 4K:

  1. Log in to bilibili.com in your desktop browser;
  2. Press F12 to open Developer Tools, go to Application -> Cookies -> https://www.bilibili.com;
  3. Find the item named SESSDATA and copy its Value;
  4. Navigate to Settings tab in OmniDownloader, paste it into the Bilibili Cookie field, and save.
