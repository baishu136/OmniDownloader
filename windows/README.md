# OmniDownloader Windows 移植版

全能多媒体音视频下载利器（Windows 原生桌面独立客户端与本地网页纯后台双形态支持）。

本工程由 Android 版 **OmniDownloader** 移植而来，保留了所有强大的音视频解析与下载能力，并针对 Windows 操作系统进行了深度优化。

---

## 🌟 核心特性

1. **主流媒体平台全支持**：
   - **哔哩哔哩 (Bilibili)**：支持单视频、多P分集与番剧合集，原生解析 DASH 视频与音频流并毫秒级无损合并，支持 SESSDATA 高清鉴权与多集批量勾选下载。
   - **抖音 (Douyin)**：支持分享口令与短链解析，自动重定向嗅探原画无水印直链。
   - **快手 (Kuaishou)**：短视频直链免水印嗅探。
   - **小红书 (Xiaohongshu)**：笔记视频极速提取。
   - **TikTok**：免登录绕过 WAF，下发 1080P/超清无水印直链。
   - **YouTube / X (Twitter) / Instagram / Facebook / Pinterest**：完整通用媒体解析引擎。
2. **丰富的导出模式**：
   - **音画合流 (MP4)**：自主选择清晰度（4K、1080P、720P、480P 等），无缝合并最佳画质与音轨。
   - **仅纯画面**：自动剥除声轨，适合剪辑、鬼畜素材二次创作。
   - **提取音频**：抽取高保真音轨并转码为 **MP3**、**M4A**、**FLAC** 或 **OPUS**。
   - **动态图 (GIF)**：基于 FFmpeg 双通道调色板分析，生成高品质免播放器预览 GIF 动图。
   - **保存高清封面**：一键保存视频高清原图缩略图到本地。
3. **两种彻底解耦的运行形态**：
   - 🌐 **网页纯后台服务版 (Web App)**：极速启动、毫秒级加载、内存占用低。启动后静默常驻右下角任务栏托盘，自动打开默认浏览器访问。**彻底剥离窗口模块依赖**，支持浏览器原生接管下载！
   - 💻 **桌面独立客户端版 (Desktop App)**：原生独立桌面窗口体验，基于 Edge WebView2 启动无边框现代化窗口，关闭窗口完全退出。
4. **深度优化与系统集成**：
   - **Material 3 配色全量继承**：界面风格与 Android 原版一致（主色 Indigo `#4F46E5`、辅色 Cyan `#0284C7`）。
   - **高分辨率高清定制图标**：托盘、EXE 及网页 Favicon 全链路适配。
   - **一键清空下载记录**：支持仅清空已结束任务或全量清空，前后台实时联动。
   - **开机静默自启动**：支持无黑框开机自动在后台启动并常驻托盘，随时在浏览器秒开访问。
   - **内置独立 FFmpeg**：免去繁琐的系统环境变量配置。
5. **v1.4.8 核心特性全面对齐**：
   - **中转站管理迁移至设置**：首页在未配置中转站点时完全隐藏占位卡片；设置页集中管理中转站点列表与一键删除。
   - **网址标题自动异步检索**：新增 `/api/relay-sites/fetch-title` 路由，添加中转站时网址置顶，700ms 防抖自动截断拉取网页 `<title>` 智能回填。
   - **直链嗅探与防 HTTP 405 拦截**：严格过滤内部 API 接口路由，防止误向 POST 接口发送 GET 请求；支持 SnapCDN / X2Twitter 等基于 JWT Base64 编码的媒体流解密。

## 🚀 开机自启动管理

已为本机成功开启开机自启动，以后电脑开机将自动在后台静默运行并常驻托盘。如需管理：

1. **一键批处理控制**：
   - 开启自启动：双击运行 [`windows/设置开机自启动.bat`](file:///f:/AGENT/Gemini/下载器/windows/设置开机自启动.bat)
   - 关闭自启动：双击运行 [`windows/取消开机自启动.bat`](file:///f:/AGENT/Gemini/下载器/windows/取消开机自启动.bat)
2. **网页端随时开关**：
   - 打开网页版（`http://127.0.0.1:58000`）-> 点击顶部【设置】-> 勾选或取消【开机自动在后台运行网页服务】-> 点击【保存设置】即可生效。
3. **系统托盘随时切换**：
   - 右键点击桌面右下角紫色云朵托盘图标 -> 点击【🚀 开机自启动】即可实时切换开关状态。

## 🛠️ 自动化打包构建

工程已将构建系统完全拆分解耦，支持独立按需打包：

1. **仅打包网页纯后台版**：
   - 双击运行：`windows/一键打包_网页服务版.bat`
   - 或执行命令：`python build_web.py`
2. **仅打包桌面独立客户端版**：
   - 双击运行：`windows/一键打包_桌面客户端版.bat`
   - 或执行命令：`python build_desktop.py`
3. **打包交互式控制台 / 双版本联合打包**：
   - 双击运行：`windows/build_exe.bat`
   - 或执行命令：`python build_exe.py --mode all`
