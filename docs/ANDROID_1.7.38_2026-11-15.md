# Android 1.7.38：Pixiv 画师主页原图与动图下载

versionCode 97。首页填入 `https://www.pixiv.net/users/14097430`，点击「立即解析」，即可按画师作品索引读取插画、漫画多页和 Ugoira，并保存所选原图或动图。

## 使用

- 默认选择已经读取的全部图片及动图。插画/漫画每页作为原图展示；Ugoira 单独标注「动图（封面）」，预览页显示「下载动图」，不会把动图封面保存成作品。
- 「保存」按页保存原图，Ugoira 按所选格式导出；「图片按作品 ZIP」将同一作品所选原图打包，动图仍按动图格式导出。
- 有 Ugoira 时显示动图格式菜单，可选择 GIF、MP4 或原始帧 ZIP。原始帧 ZIP 保存帧序和 `frames.json` 时长；GIF 受 10ms 时间粒度及调色板限制，需要完整保留时序与像素时可选择原始帧 ZIP。
- 可停止并继续，已经取消选择的图片不会因后续作品加入而被反选。一次最多解析 100 个作品，较大画师主页可继续读取；只有初始索引中的作品都成功读取，才显示「已完成」。扫描结果在当前应用会话内保存，重启后需重新解析；已生成的下载任务按原作品链接持久化，不需要重新扫描画师主页。
- 图片沿用设置中的图文保存目录；Ugoira 沿用现有动图/视频下载目录。每次最多加入 500 个任务，较大图库可减少选择或按作品打包。
- 批量页也支持画师主页：完整读取后按作品创建图片 ZIP 和 Ugoira GIF 任务。超过本轮解析上限时明确报告未完成，不把部分作品当成全量加入队列。

## 实现与保护

支持 Pixiv 主域、www/touch 域及部分语言前缀下的 `/users/<id>`、`/artworks`、`/illustrations`、`/manga` 画师路径。这些入口均读取该画师可见的插画/漫画作品集合；收藏、关注、小说及相似恶意域名不会误识别为画师作品页。

使用 Pixiv 官方网页的用户信息、`profile/all`、`profile/illusts`、作品 `pages` 和 `ugoira_meta` 接口，不新增第三方解析服务。索引去重后按作品 ID 排序，并发读取最多两个作品。核对画师 ID、作品 ID、归属用户、分页数量和原图文件路径；不使用推荐、收藏、头像或权限占位图补全资源。动图需有有效帧时序和属于目标作品的帧包地址。解析和索引合并在后台执行，HTTP 请求支持协程取消。

账号 Cookie 继续由 Pixiv 会话档案提供，服从开关及域/路径范围；会话或代理改变后不拼接旧作用域的分页。遇到登录、权限、限流或作品失败，会保留已确认结果并报告尚未完成。这里只能读取平台对当前会话提供的作品，不绕过私密、R18、好友或其他访问限制；单作品图片数沿用当前最多 200 页的处理边界。

下载任务固定到 `/artworks/<id>`：原图使用现有图片管线，Ugoira 使用现有 GIF/MP4/原始帧导出管线。不会将 Ugoira 封面作为 IMAGE 任务。已有 X 主页、图文、批量、GIF 管理及滚动优化保持兼容。

## 修复 Ugoira GIF 末帧时序

新动图验证发现既有 GIF 编码把 concat 的终点重复帧也写入输出，GIF muxer 又默认复用上一帧停留时间：80/230/390ms 三帧输入，总长 700ms，却得到四帧 1090ms。现排除终点重复帧，并显式设置 GIF 最后一帧的停留时间。相同 Android 原生测试恢复为三帧 700ms；MP4 和原始帧 ZIP 的时序验证也通过。[FFmpeg GIF muxer 文档](https://ffmpeg.org/ffmpeg-formats.html#gif-2)说明 `final_delay` 使用百分之一秒，默认复用上一帧延时。

## 验证

- 267 项 JVM 测试通过：画师 URL、索引去重/排序、作者身份、多页原图、缺页/占位图拒绝、Ugoira 分类及三种动图任务规划；新增 JSON 依赖仅用于 JVM 测试，不进入 APK。一次并行构建期间既有 HTTPS 代理用例出现 Socket closed，构建结束后全套重跑通过，日志保留。
- 114 项共享 Python 引擎测试通过；Python extras 和已有运行时依赖未更改。
- 示例画师公开索引实测包含 16 个插画作品、19 张原图，无 Ugoira。通过 Android 生产解析及下载入口完整保存 19 张原图，总计 90,660,154 字节，每张尺寸均与原图元数据一致；测试成品随后移除。
- 8 项设备回归通过：三种动图实际导出、菜单与选择、X 分页选择保留、首页共享输入、多图滚动/回顶及批量预解析完成清理。GIF 测试使用三张不同颜色的 101×99 PNG，80/230/390ms；GIF 三帧 700ms，MP4 按编码要求补齐为 102×100，ZIP 保存三帧及 700ms 时序。
- Release 构建、Lint（0 errors、52 warnings）和原签名验证通过；R8 正式包冒烟结果随本地交付 `qa/results.json` 保存。

本轮仅交付 Android，未替换 Windows、iOS 或本机 Web，未公开发布至 GitHub。没有实体 ARM64 手机可用；原生下载和转换由 Android 15 x86_64 模拟器验证，正式包 UI 冒烟跳过 ARM64 原生执行。示例画师没有动图，因此该主页的全量原图验证与受控 Ugoira 导出验证分别记录，不将两者混称为该画师的真实动图下载。
