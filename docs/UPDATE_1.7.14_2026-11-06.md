# OmniDownloader Android 1.7.14

- 修复部分抖音图文链接只返回作品 ID、无法解析的问题。提供的分享链接已能解析出完整的 21 张图片；遇到平台验证时仍会提示完成验证。
- 深浅色主题切换增加平滑颜色过渡，减少页面、系统栏瞬间跳色；快速连续切换时延续当前过渡，保留页面内容与输入。
- 网络代理新增「连通性测试」，分别显示国内、国际站点连接状态和耗时。可先测试未保存的地址；地址错误会直接提示，保留原设置。补齐图文解析的 SOCKS5 支持。
- 首页支持平台列表根据实际宽度排列，省略按钮紧随第二行末尾的平台；展开、收起加入过渡动画，宽屏能完整显示时不再折叠。
- 下载选项中的自适应最高画质使用当前可用格式的最高已知分辨率与对应大小作为展示参考，减少「待确认」。平台未提供的大小仍显示待确认。
- 图文页平台名称改为 bilibili，移除图片列表上方冗余说明。

安装包：`release/1.7.14/OmniDownloader-1.7.14-arm64-v8a.apk`。

当前代理支持免认证 HTTP CONNECT 与 SOCKS5 地址；不支持的协议或需要账号密码的代理会明确提示。连通性成功代表测试站点可连接，不代表所有平台解析或下载均可用。
