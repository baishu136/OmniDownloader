# OmniDownloader Android 1.7.13

## 使用变化

- 下载选项移除顶部“最高源画质”菜单及其说明，直接选择下方具体格式。视频选项统一显示分辨率、格式和大小，减少编码、帧率等附加文字；平台未提供的信息显示待确认，不编造大小。
- 保留 MP3、M4A、FLAC、OPUS 音频导出。声音已包含在 MP4 中的视频也可显示音频下载，不再要求必须存在独立音轨列表；按当前选中视频判断，静音源和 Pixiv 帧动画不显示无意义的音频入口。
- 账号页移除重复的 YouTube Cookie 卡片，YouTube 继续通过统一平台会话入口导入和管理。通用平台菜单移除哔哩哔哩，保留原有哔哩哔哩专用登录和会话管理；已保存会话不清除。
- 首页平台标签默认简洁显示，点击末尾省略按钮展开完整的 12 个已命名平台，补齐 Pixiv、小黑盒，并可收起。
- 中转网站列表保存展开或收起状态，下次打开继续沿用上次选择。

## 兼容与验证

- 当前工作项目为 `F:/AGENT/Gemini/下载器`。Android 1.7.13 / versionCode 72；未修改 Windows、iOS 或共享 Python 归档，未提交、推送或公开发布。
- Pixiv 格式展示使用作品接口已有尺寸，保留 MP4、GIF、ZIP + JSON 三种导出选项；这些属于导出格式，不能被“最高源画质”排序替换。编码、帧时序、帧资源和原下载校验仍保留。
- 126 项 JVM 测试通过，覆盖合流/独立音轨判断、静音源、当前子视频差异、简洁格式展示、未知信息和 Pixiv 导出选择保护。
- API 35 x86_64 只读 Omni 模拟器上 6 项交互回归通过：平台标签展开与状态恢复、音频导出入口与格式回调、Pixiv 三种导出选择、账号菜单、偏好重读以及实际主页活动重建后的展开/收起恢复。音频测试夹具改用可观察选择状态后，另有 1 项针对回调的检查通过。
- 已检查 8 张原生截图，包括实际主页、状态恢复、账号菜单及下载选项。布局测试使用隔离数据，不把测试作品当成在线作品验收；测试添加的网站及临时语言/引导/展开偏好均恢复。初轮测试错误使用了不存在的简写 FLAC 标签，已改为现有完整标签；首次绘制前的空白截图及后续重拍结果均保留在忽略提交的 `.local/1.7.13/`。
