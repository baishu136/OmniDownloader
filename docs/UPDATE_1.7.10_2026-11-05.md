# OmniDownloader Android 1.7.10

## 使用变化

- 修复 Pixiv 网页登录打开“尚无此页”的问题，改用当前登录入口，并明确提示登录后保存会话。
- 修复部分仅对 `www.pixiv.net` 生效的已导入会话未进入动图解析/下载请求的问题，仍遵守 Cookie 禁用开关。
- 对已确认存在的受限动图，资源接口返回 404 时提示重新登录、保存可访问该作品的账号会话，不再把这一情形误报为作品已删除。

## 诊断与边界

用户提供作品 `151704267`，并确认同一账号可在普通浏览器打开。未登录的第一方请求实测：旧 `accounts.pixiv.net/login.php` 返回 404，当前 [Pixiv 登录入口](https://accounts.pixiv.net/login) 返回 200；作品信息接口返回 200，ID 匹配、类型为动图且带有限制标记；动图资源接口返回 404。本轮只读取接口与登录页，没有下载或展示作品媒体。

只有在已成功读取、验证作品信息且确认有限制标记后，其动图资源的 404 才按登录/会话问题处理。普通作品的 404、明确的 410、网络故障和平台限流保留独立错误分类，不通过匿名重试或其他作品替代资源。

安装后进入“设置 → 账户与会话 → Pixiv”，确认未禁用 Pixiv Cookie，使用能打开该作品的账号重新网页登录并保存会话，再解析链接。**没有取得用户的真实账号会话，登录后的受限资源解析与实际下载尚未代用户验收。**
