# OmniDownloader Windows 1.7.64

完整解压整合 ZIP，启动 `OmniDownloader_WinUI.exe`。原生客户端与网页版共用本地下载服务、任务及配置；账号和开机启动在客户端设置管理。

本次界面调整：

- 网页应用名和版本移至左上角，下载输入区上移，减少顶部空白。
- 输入框聚焦时只改变底部线条，不再出现内层方框；保留键盘可见焦点。
- 视频解析后的下载选项在输入框下方直接排列，没有全屏遮罩、弹窗或内部滚动容器。
- 客户端复用原格式选择逻辑，改为页内控件，保留视频、音频、GIF、画质、容器、合集多选、封面及提交失败处理。提交期间防止重复点击。
- 修改链接或清空输入时，网页隐藏旧下载选项；重新解析后显示新结果。图文、批量、下载进度与主题切换保留。

构建：`.venv/Scripts/python.exe tools/build_unified_windows.py`。

如果已在运行旧托盘服务，需从旧托盘正常退出后重连新版客户端，才能加载新后端；不强制终止旧服务或覆盖运行中的程序。用户配置继续存放于 `%LOCALAPPDATA%/OmniDownloader`。
