# OmniDownloader Android 1.7.16

修复 GIF 下载、视频转 GIF 后无法查看的问题，同时修复抖音下载地址失效后的恢复，以及抖音、小红书只显示 720P 的部分场景。

- 修复直链校验拒绝标准 GIF、拒绝小于 1 KiB 的合法 GIF 的问题。原生 GIF 保留原始动画帧与文件内容，不因扩展名误判媒体格式。
- 修复 FFmpeg 运行库解压不完整但版本标记仍有效时无法转换的问题。启动和转换前检查包内库的大小及 ELF 头，从原安装资源恢复缺失、截断或 ABI 不匹配的库，恢复时核对 CRC。
- 视频转 GIF 使用两次处理生成和应用调色板，避免单一 split 图积压整段视频；明确输出 GIF 编码与容器。转换失败会报告失败，不再保存 MP4 后将任务标为 GIF 完成。
- 导出前检查完整 GIF 块结构和 Android 解码能力；截断文件、缺失结尾及改名 MP4 不会被作为成功 GIF 导出。旧版本错误缓存不再阻止重新生成。
- 任务查看、分享按实际文件内容及 MIME 类型处理，兼容旧版本留下的“GIF 任务、MP4 文件”。

- 抖音合并目标作品不同响应中的播放格式，兼容桌面端字段。浏览器提取同时读取当前可见播放器的实际媒体尺寸，避免先拿到的 720P 详情遮住已经播放的 1080P。解析成功后可通过“浏览器读取更多画质”再次提取。
- 浏览器播放器必须带有目标作品 ID，或与目标详情返回的视频地址关联；不再仅凭页面地址把验证页的占位动画当作目标视频。
- 小红书继续读取平台返回的原始视频地址，并通过有上限的 MP4 分段探测确认尺寸。支持超过 4 GiB 的文件及较大的尾部元数据，兼容 CDN 缩短 Range 响应和短暂 5xx。原源尺寸暂未确认时，保留原源选项并明确提示，避免将当次 720P 列表当作最高画质。
- 国内视频地址遇到过期、连接异常或 CDN DNS 失败时，在限定次数内切换同一作品、符合已选画质的备用源，必要时重新解析；不自动降至不符合选择的低画质。
- 自动换源期间保持任务进行状态，避免单个地址失败就提前显示整个任务失败。
- 断点续传校验媒体地址、服务端验证标识和 Content-Range；切换视频源前丢弃旧片段，防止跨源拼接和错误的“下载完成”。
- Android 打包的 Python 备用解析同步保留小红书原源能力，原生网络解析失败时仍可使用。

验证结果：159 项 JVM 测试、17 项共享 Python 回归测试通过；5 项浏览器离线场景通过。GIF 的 5 项 Android 端到端测试覆盖原生 GIF、普通视频转 GIF、扩展名伪装的视频、损坏输出拒绝、FFmpeg 库故障恢复。导出 GIF 的系统 MIME 为 image/gif，Android 图片解码器及应用 Coil 预览均通过；原生 GIF 动画帧内容发生实际切换，视频转换成品为 480×853、15 帧、1 秒。

Android 15 x86_64 模拟器中，使用此前从目标抖音作品捕获的详情，模拟首地址失效后实际下载为 1080×1920、含音轨、约 12.45 秒，并验证换源期间不提前发布失败状态。小红书样本连续 3 次应用解析、1 次包内 Python 解析均得到 2160×3840 原源。

最终版内置浏览器的抖音在线复测遇到登录和滑块验证码，未完成目标提取验收；已记录截图，未自动处理验证码。遇到此页面时，应先在应用内完成验证、打开目标作品，再提取画质。验证页动画不能作为提取成功的证据。

压缩后的 ARM64 Release 安装包已在隔离模拟器通过冷安装、历史记录恢复、页面导航和设置子页检查。该检查跳过 ARM64 原生程序执行；GIF 转换执行测试使用与模拟器架构相符的 x86_64 调试包。Release 构建和静态检查通过（0 个错误、46 个警告）。

小红书原文件约 18.86 GiB，本次只探测元数据，没有完整下载或验证其 HDR 色彩信息。实测使用开发机 HTTP 代理；模拟器直连 DNS 曾失败。本次没有连接 ARM64 真机，不能替代实际手机、账户及网络环境验收。平台只提供低清源或要求登录验证时，应用仍需遵循平台当前返回结果。

安装包为 `release/1.7.16/OmniDownloader-1.7.16-arm64-v8a.apk`，版本号 1.7.16、版本代码 75。使用现有项目签名，保持 ARM64、Android 8.0 及以上支持范围。本次仅交付本地安装包，未更新 GitHub Release。

覆盖安装后，请重新下载之前无法查看的 GIF 文件；新任务会使用修复后的转换与成品校验流程。

格式及解码参考：[GIF89a 规范](https://www.w3.org/Graphics/GIF/spec-gif89a.txt)、[Android ImageDecoder](https://developer.android.com/reference/android/graphics/ImageDecoder)。
