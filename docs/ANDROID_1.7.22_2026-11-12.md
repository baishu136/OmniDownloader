# Android 1.7.22

本轮范围仅 Android。版本 1.7.22 / versionCode 81，保留原签名及 ARM64 原生组件。

## 设置与 GIF

- 根页面直接选择语言，不再进入“外观与语言”子页。
- 主题选择位于“偏好设置”同一行右侧，支持跟随系统、浅色、深色。
- 新增 GIF 子页，列出本应用下载/转换的 GIF，支持打开、分享、删除文件与记录、取消及重试任务；删除前确认，不删除原视频。
- 使用系统 OpenDocument 选择视频，只读取用户选择的文件并保留读取授权。视频流式复制到任务私有目录，复用现有双 Pass GIF 转换、成品验证及导出流程；输入副本转换后清理。导出失败保留验证过的成品，重试可直接导出。
- GIF 列表使用惰性布局；进度变化不重复触发整个历史文件的 MIME 查询。

## 后台与解析

- 用户发起解析时使用现有 dataSync 前台服务显示通知，按解析 token 管理保活；结束旧解析不会结束新解析，空闲时退出服务并释放唤醒锁。
- 下载请求按任务 ID 去重，忽略已结束任务的重复启动；取消会取消实际工作协程及原生处理，工作结束后再继续队列。异常与取消路径均归还工作占用状态。
- 任务回调附带执行代次检查；下一项异步调度，避免缓存成品批量导出时递归执行。导出前已有严格成品验证，不再在服务同步锁内重复探测视频。
- 统一短链恢复入口；只缓存确认过的内容页身份，30 秒、最多 64 项、按代理区分。不缓存登录/验证失败、未完成的短链及媒体流。
- 短链请求使用可取消的异步 OkHttp 调用；取消协程会关闭调用与响应，取消异常不会伪装成网络失败。

## 实际检查

173 项 JVM 测试通过，包括缓存过期、代理隔离、容量限制及慢速重定向取消回归。Android 15 x86_64 模拟器实际验证设置根页语言/主题、GIF 入口、后台本地视频转 GIF、Android ImageDecoder 多帧解码、原视频保留、重复启动，以及取消前项后后项完成。解析 token 的交错结束与空闲退出也已验证。

Release 构建与 Lint 通过，优化包界面冒烟测试通过。ARM64 安装包的原生载荷与既有版本保持一致；实际原生命令测试使用 x86_64 测试构建，不能当作 ARM64 真机验收。

未测真实设备厂商省电策略、全部生产平台链接或强制结束应用后的继续执行；后台解析在应用进程及其解析任务仍存活时获得前台服务保护，不承诺绕过系统终止或验证码。没有可比较的生产平台测速数据，因此不声称固定百分比加速。

平台依据：[前台服务启动](https://developer.android.com/develop/background-work/services/fgs/launch)、[dataSync 用途](https://developer.android.com/develop/background-work/services/fgs/service-types#data-sync)。
