# OmniDownloader 1.7.29

本次更新 Android 版，支持 Android 8.0 及以上 ARM64 设备。

## 新功能

- 新增批量下载页面，支持智能识别分享文本、逐条添加链接、自动去重及合集/多视频下载，每批最多添加 100 条链接。
- 新增双路并行解析：不同平台可同时解析，同一平台依次处理；单条失败不影响其他链接。
- 新增批次处理记录清空按钮，清空记录时保留已填链接、下载任务及文件。
- 设置新增 GIF 页面，可管理已下载的 GIF，并支持选择本地视频转换为 GIF。

## 优化

- 图文与视频下载合并到首页，共用输入框；图文保存目录移至“设置 → 下载与存储”。
- 批量输入支持无换行拼接链接和剪贴板自动添加，退出后保留草稿及未完成链接。
- 优化图文预览为自适应多列布局，精简批量下载页面说明。
- 中型按钮改为中圆角，底部导航新增切页图标填充动画。
- 语言选项直接显示在设置页，深浅色模式入口移至“偏好设置”右侧。
- 优化后台解析、任务调度、取消与重试，提升下载稳定性。

## 修复

- 修复部分哔哩哔哩视频的解析及分段下载问题，改进失效媒体源的刷新与重试。
- 修复下载任务切换时网络阻塞导致界面卡顿、取消操作无响应的问题。
- 修复 YouTube 选流探测使用不可写临时目录而导致下载失败的问题。
