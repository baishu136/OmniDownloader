# OmniDownloader Android 1.7.7

## 使用变化

- 在视频页、图文页粘贴了另一类作品链接时，自动进入对应页面并接着解析，无需重新粘贴。视频继续显示格式选择，图文直接显示图片列表。
- 图文输入框增加与首页一致的粘贴、清空按钮；清空或更换链接可取消正在进行的解析，旧结果不会覆盖新输入。
- 图文解析按钮移到右侧，左侧增加保存路径入口，可选择系统授权文件夹或恢复默认目录。路径与现有下载设置一致，重启后保留。

## 验证与边界

本轮仅修改 Android，versionCode 为 66，最低 Android 8.0（API 26）不变。沿用现有视频/图文解析器、会话、下载任务与导出机制，没有改变 Windows、iOS 或公开发布状态。

- 107 项 JVM 测试通过，包含双向接续、明确/不明确类型、作品验证、取消、最多一次备用解析，以及网络/登录/权限错误处理。
- 3 项模拟器 Compose 测试通过：粘贴/清空/解析状态、目录菜单操作、320dp 与 1.8 倍字体下的按钮布局。
- API 35 x86_64 模拟器实际链接验证：视频页 → B站图文（4 张 GIF）；视频页 → 快手图集（10 张）；图文页 → 小红书视频（打开真实格式选择）；视频页 → 小红书图文（7 张）。没有发起媒体下载。
- 系统文件夹选择器实际授权 Pictures 成功，重新启动应用后仍显示该目录。取消、恢复默认入口沿用现有目录设置机制。
- 快手视频样例本次返回 `MEDIA_ID_MISMATCH`，没有伪装成成功；未修改作品校验或用推荐视频替代。平台登录、验证、访问权限、网络与现有解析器限制仍然适用。未进行实体手机验证。
- ARM64 Release 构建、R8、lintVital 通过；APK ZIP CRC、随包 Python 依赖完整性、v2 签名、ABI、版本与 SHA-256 校验通过。签名与本地 1.7.6 相同。
- 构建前冻结 168 项 Android 源码、资源、测试与构建输入，构建完成后内容未变。

真实链接验证从独立冷启动开始，避免旧页面内容影响结果判定。早期连续分享脚本曾读到其他样例的旧页面，相关记录已标为无效，不能用于声称热启动分享全流程通过。最终有效结果及原始诊断保留于忽略提交的 `.local/1.7.7/`；未导出账号、Cookie 或完整私有分享链接。
