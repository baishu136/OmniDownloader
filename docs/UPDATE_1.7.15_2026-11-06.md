# OmniDownloader Android 1.7.15

- 修复代理地址留空时，点击连通性测试可能闪退的问题。留空会测试当前手机网络，测试结束后可继续操作。
- 支持 HTTPS 代理服务器地址，继续支持 HTTP 和 SOCKS5。无效地址、证书异常与连接失败会明确反馈，不自动改成不安全的明文连接。
- 修复部分抖音视频把上传尺寸当作实际播放流尺寸的问题，避免将实际 720P 的资源显示为 4K。
- 修复小红书部分图文将原图尺寸标到缩略图上的问题，按当前返回资源显示尺寸；无法确认时保留未知状态。

HTTPS 地址应是代理服务器端点，例如 `https://proxy.example:443`。订阅链接需要先导入兼容的代理客户端，再使用客户端提供的 HTTP／SOCKS5 地址。

安装包：`release/1.7.15/OmniDownloader-1.7.15-arm64-v8a.apk`。
