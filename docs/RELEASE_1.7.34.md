# OmniDownloader 1.7.34

本次更新 Android 版，支持 Android 8.0 及以上 ARM64 设备，包含 1.7.30–1.7.34 的更新。

## 新增与优化

- 批量链接添加后自动提前解析，点击开始时复用有效结果或等待正在进行的解析；提前解析不会自动创建下载任务。
- 下载全部完成的链接自动移出“已填链接”；合集须全部分集完成，失败或未完成的链接继续保留。
- 移除或清空链接时同步取消对应解析并清除结果，避免迟到响应恢复记录或误加入下载队列。
- 设置、批量下载及保存路径菜单统一采用 Cherry Studio Mobile 风格，加入圆角悬浮面板、右侧选中标记、回弹展开和滑入淡入动画。
- 优化抖音渐进式解析与等待预算，先展示已确认结果，再补充可用的更高画质。

## 修复

- 修复 X 公开接口空响应被误判为“帖子 ID 不匹配”、导致解析回退中断的问题。
- 修复部分 X 空 JSON 错误未触发回退，以及空 id_str 未使用同一响应中正确 id 的问题；仍拒绝明确返回其他帖子的内容。
- 改进 X 公开解析的有限重试和超时控制，保留多视频定位、原有画质选择及 HLS 配套音轨。
- 修复小红书图文图片和视频封面使用带平台水印的 H5 预览资源的问题，按同一图片 ID 获取标准图片源；保留作者原有文字与标记。
- 改进抖音播放地址处理与媒体源确认，减少异常短片段和重复等待。
