# OmniDownloader 1.7.65 / Android 1.7.62 发布说明与技术记录

Windows 整合包完整解压后运行 `OmniDownloader_WinUI.exe`（正式发行于 [GitHub Release v1.7.65](https://github.com/baishu136/OmniDownloader/releases/tag/v1.7.65)）。网页版和客户端共享后台，首次运行提供引导设置（自定义主题色、视频/图片含GIF/音频分类目录及网页服务开关）；关闭窗口可选择退出或最小化到托盘并记住选择，若关闭网页服务则退出主程序时将清理全部分支后台与组件进程；右键托盘可选择显示窗口、拉起网页版（未开启网页服务时自动隐藏）或退出程序。

## 补充新增与界面升级（WinUI 3 + Web + 全端对齐）

- **自定义主题与组件管理**：支持在设置内配置主题强调色并实时同步网页版；原“下载引擎与组件”升级为“组件管理”，展示名称与简要说明并在右侧显示启用/就绪状态，核心必需组件锁定不可取消勾选，并支持新增自定义扩展组件入口；首页新增“最近任务”展示开关（默认开启）。
- **网页版重绘与客户端打磨**：网页版参照 BilibiliDown 设计语言重构交互并继承客户端配色，修复下拉选单展示；打磨 WinUI 3 页面导航滑块动画、内置视频播放器 UI 及封面图代理加载稳定性。
- **登录会话修复**：移除各平台 Cookie 登录中的 Pinterest 登录服务；修复桌面端内置哔哩哔哩浏览/SESSDATA 登录拉起、Android 端 Instagram 登录页及快手登录恢复链路。

## 下载类型

| 语言 | 视频 | 纯画面 | 音频 | GIF |
| --- | --- | --- | --- | --- |
| 简体中文 | 视频 | 纯画面 | 音频 | GIF |
| 繁體中文 | 視頻 | 純畫面 | 音訊 | GIF |
| English | Video | Video only | Audio | GIF |
| 日本語 | 動画 | 映像のみ | 音声 | GIF |

名称用于 Android、iOS、Windows 客户端和网页的类型选择、批量入口及任务类型徽章。音频编码选项继续保留 MP3/M4A/FLAC 等真实格式。下载类型的内部协议 ID 与历史任务数据格式保持兼容。

## 媒体处理修复

- GIF 选择“视频”或“纯画面”时，解码动画帧并编码为 H.264、YUV420P 的 MP4；不把 GIF 字节直接写入 `.mp4`。奇数尺寸使用边缘填充，GIF 原本没有音轨，不伪造音轨。
- MP4 选择 GIF 时，实际生成调色板并编码 GIF；根据文件签名、完整块流及解码结果校验，不能通过修改后缀冒充 GIF。
- Windows 校验导出前缓存，恢复旧 MP4 缓存时执行实际转换；转换失败保留原始缓存。
- Android 防止同路径转换先删除源文件，所有 GIF 导出继续执行内容校验。iOS 同步相应转换与缓存恢复逻辑。

## 多语言

补齐静态 UI、无障碍标签、画质大小占位与设置说明的翻译。Windows 原生静态文案通过明确的附加属性接入语言切换，避免改写媒体标题、作者、网址等用户数据。iOS 原先未接入的 SwiftUI 静态文案调用统一翻译入口。

共享补充词条位于 `shared/localization/supplement.json`。运行 `python tools/sync_client_assets.py --translations-only` 可合并 Android 词条与各端已有词条，不清空平台特有翻译，也不修改浏览器捕获脚本。运行 `python tools/audit_localization.py` 检查缺词、英文混入汉字/假名、占位符和下载类型一致性。

语言自称、平台品牌、媒体标题/作者以及第三方原始诊断信息允许保留原文；这类内容不算应用自身文案漏译。静态扫描不能替代所有页面与网络错误分支的人工验收。
