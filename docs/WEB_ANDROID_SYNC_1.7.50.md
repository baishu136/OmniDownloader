# Web 1.7.50 Android 功能同步

首页新增微博、西瓜视频、Reddit、Twitch、优酷、爱奇艺、AcFun、虎牙、TED 和 Internet Archive 等平台标签。展开后可搜索实际安装的 yt-dlp 解析器，过滤上游标记失效的项目。平台标签行高和间距统一，展开支持系统减少动态效果设置。

微博支持正文、视频页和短链，Cookie 可在账号设置中导入。通用合集每次解析最多 100 条，多视频条目用真实媒体 ID 定位。保留真实但尺寸未知的视频格式，并排除受保护的流。

完成任务可以在浏览器查看，服务支持范围请求。能否直接播放取决于浏览器的编码支持，仍可使用保存操作下载文件。文件已移动或任务未完成时返回错误。

启动自动检查官方 GitHub 正式版 Web ZIP，关于页可手动检查并打开官方更新链接。

## 构建与验证

运行 `.venv/Scripts/python.exe -m pytest windows/tests -q`，再运行 `.venv/Scripts/python.exe windows/build_release.py --mode web`。输出在 `windows/dist/1.7.50/OmniDownloader_Web`，ZIP 在 `windows/release/OmniDownloader_Web-1.7.50.zip`。

本轮从本地 origin/main 补齐工作目录中落后或缺失的 Windows 核心与构建输入，沿用既有设置、会话和任务持久化机制。

验证包含后端回归、平台目录、更新筛选、合集媒体身份、完成文件范围请求，以及桌面和窄屏浏览器交互。使用本地视频夹具实际执行 HTML 解析、下载、导出和浏览器查看。真实微博账号和全部第三方平台尚未逐一端到端验证。

本机替换前备份原程序和用户状态，重启后核对历史任务 ID、设置及会话状态。正在执行的下载应先结束。

本轮最终结果为 97 项后端测试通过。独立 EXE 和替换后的 58000 服务均已真实启动，浏览器平台目录搜索通过，官方更新检查返回 HTTP 200。替换后 3 条历史记录、原设置和会话状态一致。微博追加在原有会话编号末尾，避免改变已保存凭证的平台归属。旧安装和用户状态备份路径记录于本机 `.local/web-sync-replacement.json`。
