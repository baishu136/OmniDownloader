# OmniDownloader 1.7.20 界面调整

本次仅修改 PC/iOS 的界面、图标和打包资源。Android 维持 1.7.19，不改动下载核心。

## PC

恢复上一版 Windows 的桌面风格：顶部导航、靛蓝到青色的渐变主按钮与标题、白色/深色描边卡片、输入框内的粘贴和解析按钮、输入框下方的平台标签。保留四页导航、七类设置及子页、账号与下载能力。浏览器辅助放入独立折叠区，避免挡住输入内容。

品牌图标使用单一 SVG 圆角裁切，移除旧内嵌位图和外部边框的双重圆角。ICO 的 16/24/32/48/64/128/256px 帧分别从矢量原生渲染，避免缩小大图时的透明边缘振铃。打包器根据图标 SHA-256 使 EXE 图标缓存失效，防止新资源被旧缓存覆盖。

## iOS

导航、设置和主要操作使用与 Android 相同的 Google Material Icons Outlined 图形，共 27 个矢量 PDF 资源；不再用外形不同的 SF Symbols 替代这些主要图标。其他系统工具栏继续使用 iOS 系统控件。

首页品牌区采用 Android 的 44pt、14pt 圆角、23pt 云下载图标和主色/第三色渐变。主按钮使用 Android 主色与前景色，次按钮使用低饱和表面色；禁用状态使用独立的前景与容器透明度。操作按钮至少 48pt 高，主要图标触控区至少 44pt。下载模式使用 10pt 圆角、20pt 图标和向内绘制的选中描边。按压使用轻量状态层，尊重减少动态效果设置；切换页面时收起键盘。

iOS 应用图标为满幅正方形，由系统施加外轮廓；未预先绘制圆角、白色底边或阴影。品牌 SVG、Material 原始 SVG、SHA-256 和 Apache-2.0 许可位于 `shared/icons`，相应许可随包提供。构建图标的开发依赖为 fonttools 4.60.1、resvg-py 0.5.0、Pillow；运行 EXE/IPA 无需这些工具。

## 交付与限制

Windows 压缩包须完整解压后运行 EXE；桌面版需要系统 WebView2。iOS 1.7.20/79 的 IPA 未包含开发者签名，需要自行签名后安装。此次没有物理 iPhone/iPad 测试，未重新验证全部生产平台链接与真实账号；1.7.19 已说明的 YouTube 格式、分享扩展和后台调度差异继续适用，见 `PARITY_1.7.19_2026-11-08.md`。

源码同步到 `codex/ui-1.7.20`，未合并 main 或创建公开 Release。恢复旧 Web 程序时先退出新版托盘，再恢复对应的版本备份目录；用户下载文件不参与覆盖。
