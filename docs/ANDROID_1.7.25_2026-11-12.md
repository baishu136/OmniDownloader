# Android 1.7.25

仅 Android，versionCode 84。首页标题、平台标签、链接输入与解析按钮布局保留，移除图文悬浮跳转入口和独立图文页路由。视频及图文使用同一输入框，沿用现有内容识别和严格目标验证逻辑；视频继续显示格式选择，图文在首页输入区下方显示选择、预览、保存及 ZIP 下载操作。输入新链接会清除旧结果；隐藏首页时不显示预览和验证浮层。兼容旧版保存的图文页导航状态。

设置 → 下载与存储新增图文下载路径：可通过系统文件夹选择器授权自定义目录，也可跟随默认下载路径。图片和图文 ZIP 使用图文目录；视频、音频和 GIF 继续使用原有目录。默认跟随原目录，不修改已有下载路径与文件。沿用原导出校验与备用目录机制。

186 项 JVM 回归通过。Android 15 x86_64 模拟器验证共用输入、图文结果选择/保存控件、切换链接清除结果、设置路径入口和实际分离导出。结果替换时图片请求绑定不可变作品快照，避免列表迟到重组读取已清空的作品。界面使用模拟作品数据，不等同于所有平台在线图文验收。

Release 构建、Lint 和优化包界面检查见交付目录 qa 的实际日志。保留原签名和六个 ARM64 原生载荷；未完成 ARM64 真机和所有平台在线验收。本轮未发布 GitHub Release。
