# OmniDownloader Android 1.7.8

## 使用变化

- 图文页顶部、输入框和操作区随图片列表一起滚动，给图片浏览留出更多空间。
- 保存路径改为可点击的下划线目录文字，保留选择文件夹和恢复默认目录入口。默认显示 `Download/OmniDownloader`；自选目录显示对应的目录位置，不再只显示最后一级名称。
- 选择计数按本轮标注显示为“已选 总图片数 / 已选图片数”。
- 全选、清空选择与保存操作集中排布；右侧依次为“打包 ZIP”“保存”。窄屏或大字体时自动换行。
- 移除图片卡片内的“平台原图 / 来源待确认”标签，保留序号、尺寸、勾选与图片预览。

## 本轮验证

- Android 版本 1.7.8 / versionCode 67。本轮仅修改图文页布局和路径文字样式，未改变解析、下载或平台鉴权逻辑；未修改 Windows、iOS，也未公开发布。
- API 35 x86_64 只读模拟器上，6 项 Compose 测试全部通过：粘贴/清空/解析、目录菜单、320dp / 1.8 倍字体布局、顶部与图片同步滚动、滚动后的选择保留、预览与保存/ZIP 操作、零选择时禁用保存。
- 实际启动新版 Android 应用，用既有公开 B站图文样例显示 4 张图片，确认新路径文字、计数、按钮和卡片标签；实际滑动后顶部位置同步变化。未发起媒体下载。
- 1.7.7 的 107 项 JVM 测试记录复用：逐项哈希确认，原有 Android 输入中只有本轮两处 UI 文件及版本配置发生变化，核心与 JVM 测试源码未改变。
- ARM64 Release 构建、R8、lintVital 通过；APK ZIP CRC、ABI、版本、随包 Python 归档完整性与 v2 签名验证通过。签名延续 1.7.7。
- 构建前冻结 169 项 Android 源码、资源、测试及构建输入，构建结束后内容一致。本轮未进行实体手机验证。

安装包：`release/1.7.8/OmniDownloader-1.7.8-arm64-v8a.apk`。校验值见 `SHA256SUMS-1.7.8.txt`；原始本地记录保留于忽略提交的 `.local/1.7.8/`。
