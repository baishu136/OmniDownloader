# OmniDownloader Android 1.7.9

## 使用变化

- 图文页上滑浏览时，“全选、清空选择、打包 ZIP、保存”操作栏到达顶部后吸顶，继续浏览长图集也能直接操作。
- 点击图片下方的信息、复选框、卡片空白及图片两侧的留白，均可勾选或取消；点击实际图像打开预览，预览不改变勾选状态。
- 吸顶操作栏实时反映选择状态，清空后保存与打包不可用，全选后恢复可用；保留窄屏、大字体下的换行排布。

## 本轮验证

- 版本 1.7.9 / versionCode 68，仅调整 Android 图文页和对应界面测试，未修改解析、会话、下载任务、Windows 或 iOS；未公开发布。
- API 35 x86_64 只读模拟器上，8 项 Compose 测试通过：目录/输入区、列表滚动与预览、滚到底部后唯一操作栏持续可见、吸顶时选择状态更新、信息/留白/复选框点击各切换一次、图像点击只预览，以及 320dp / 1.8 倍字体下的排布。
- 使用真实快手 10 图图集启动新版应用，验证信息区勾选后计数从 10/10 变为 10/9、点击图像打开 1/10 预览、上滑吸顶、吸顶状态下清空与全选。没有触发保存或 ZIP 下载任务。
- 真实界面自动检查最初误把按钮内部文字的 `enabled` 属性视为整个按钮状态；检查父按钮后确认禁用正确，并在原会话完成后续全选验证。未因此修改产品逻辑，原始诊断留存在本地。
- 复用原先 107 项 JVM 测试记录，哈希确认核心与 JVM 测试源码未变；本轮变化仅为图文页、界面测试和版本配置。
- ARM64 Release 构建、R8、lintVital 通过；版本、ABI、APK ZIP CRC、Python 依赖归档及 v2 签名验证通过，与 1.7.8 本地签名相同。构建前后冻结的 169 项输入一致。
- 本轮未连接实体手机。原始记录保留于忽略提交的 `.local/1.7.9/`。

列表采用现有依赖提供的原生吸顶操作栏，并按可见行加载图片，未增加依赖或滚动轮询。实现参考 [Android 官方列表与吸顶说明](https://developer.android.com/develop/ui/compose/lists#sticky-headers)。

安装包：`release/1.7.9/OmniDownloader-1.7.9-arm64-v8a.apk`，校验值见 `SHA256SUMS-1.7.9.txt`。
