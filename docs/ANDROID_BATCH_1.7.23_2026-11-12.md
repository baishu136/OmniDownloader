# Android 1.7.23：批量下载

仅更新 Android，versionCode 82。延续 1.7.22 的设置、GIF 和后台任务修复。

## 使用

首页点击“批量下载 · 多链接 / 分享文本”，粘贴多条链接或平台分享文本，选择音画合流、纯画面、纯音频或 GIF 后开始。音频可统一选择输出格式。每批最多 100 条去重后的链接、500 个下载任务，单条链接最多展开 100 个分集；超过限制会明确提示，不静默截断。

视频使用最高可用画质，图文自动保存为原图 ZIP。默认下载链接对应的视频；需要展开合集或同一作品的多段视频时，勾选“下载合集 / 多视频的全部分集”。支持平台与登录条件沿用现有单链接解析能力，批量入口不自动抓取用户主页或无限分页。

按链接顺序解析并交给现有前台下载服务；已入队的下载可以与后续链接解析同时进行。单条链接失败后继续处理其他链接。批次统计表示解析及入队结果，下载是否完成请查看任务页。

“停止添加”会取消当前解析及尚未处理的链接，已入队任务继续下载；下载取消、重试及成品打开仍在任务页操作。“继续 / 重试未入队条目”沿用原批次设置，不重新提交已入队条目。需要登录或验证码时，可对失败条目“单独解析 / 验证”，再重试。

## 恢复与数据

- 仅保存最近一次批次；新批次不删除已有下载任务。
- 批次链接、格式、分集选项、状态和任务 ID 使用现有 Android Keystore 加密后保存到应用私有存储。
- 页面关闭不取消正在处理的批次。Activity 重建保留输入和选项。
- 进程重新打开后，不自动重放网络请求。未处理条目可手动继续；恢复时核对任务记录，缺失的任务可以补充。
- 同一批次条目的任务 ID 由条目 ID 与真实媒体身份确定，重试、分集顺序变化时保持稳定；入队前核对仓库记录，并复用服务的 ID 去重。
- 系统终止后的既有下载任务沿用任务页的取消/重试语义，不承诺强制结束应用后继续运行。

## 验证范围

179 项 JVM 测试通过，其中 6 项批量回归覆盖分享文本提取、保留签名参数及分集位置、链接去重、批次容量、单条失败继续、取消、重试、恢复时核对缺失任务、分集身份及顺序变化。

3 项 Android 15 x86_64 模拟器测试通过：使用真实本地 1080P HLS 源验证两条视频后台下载、重复链接只提交一次、404 条目不阻塞后续下载、批次加密与恢复、缺失任务核对；取消阻塞中的实际元数据解析进程后，当前及下一条均取消且未生成任务；界面验证首页入口、选项、按钮可用状态及 Activity 重建输入保留。Release 使用实际 R8 优化包进行界面冒烟检查。

ARM64 原生组件和签名与既有安装包核对。模拟器不能替代 ARM64 真机及厂商省电策略验证；未逐个平台进行生产链接批量验收。平台登录或验证码仍可能要求用户操作，批量功能不会绕过验证。
