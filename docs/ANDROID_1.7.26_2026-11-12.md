# Android 1.7.26

本轮仅 Android，versionCode 85。

批量页移除录入方式介绍、自动保存及画质说明、继续处理的设置说明和进度含义介绍；保留标题、模式、格式、分集选项、按钮、数量、处理状态、错误与清空确认。

首页图文结果按可用宽度排列：手机竖屏两列，宽屏三列，末行不足时保留对应列宽。保持单一惰性滚动列表，保留图片预览、选择、保存和 ZIP 下载。

Android 15 x86_64 模拟器检查两列和三列卡片的实际坐标、旋转后的选择/下载入口、切换链接清除结果以及设置路径与分离导出。Release 构建、Lint 与优化包检查以 qa 日志为准。六个 ARM64 原生文件与原签名延续 1.7.25；未完成 ARM64 真机及所有在线平台验收。未发布 GitHub Release。
