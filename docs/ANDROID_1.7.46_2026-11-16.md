# Android 1.7.46：仅图文保存键在保存期间变灰

versionCode 105。将 1.7.45 新增的保存期间灰显效果限定到图文列表「保存」按钮；该键仍显示「保存中…」，任务结束后恢复。

打包 ZIP 和大图查看器保存键恢复通常样式与文案，不再跟随保存状态变灰。重复提交仍由业务层阻止，点击时提示「图片正在保存，请稍后重试」。没有选择图片时的原有禁用规则保留，主页解析取消修复也继续保留。

7 项 Android 模拟器界面回归验证图文保存键禁用、ZIP 与查看器按钮仍可点击、点击不会新增重复任务、任务结束后保存键恢复，以及既有图片选择、布局和查看器导航。JVM 回归、正式包构建、Lint、签名及 R8 界面冒烟结果保存在交付目录 qa。

仅交付 Android ARM64；未更新 Windows/iOS、本机 Web 或 GitHub。未验证实体手机，正式 ARM64 包在模拟器仅做界面和资源解压检查。
