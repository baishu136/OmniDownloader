# Web 与 Android 1.7.51

Web 首页使用统一媒体解析入口，解析结果为视频时显示格式选择，为图文时显示图片选择和原图、ZIP 保存操作。侧栏新增批量下载，移除单独图文入口、工作空间标签与首页说明副标题。平台标签默认全部展示，完整 yt-dlp 目录可直接搜索。完成的最近任务可在新标签页打开视频或图片，其他任务可进入任务页。

批量页支持分享文本、TXT、100 条链接去重、下载类型、音频格式和全部分集。每批最多 500 个任务，通用合集单链接最多 100 集。图文自动 ZIP，也可以指定逐张图片。解析完成后调用已有任务系统，下载完成数从真实任务状态计算。解析失败和停止的链接可重试，已提交条目会保留任务引用，服务重启后可恢复批次记录。批次文件使用既有 Windows DPAPI 加密机制。停止添加会中止后续提交，已经提交的下载可在任务页取消。

Android 在导出 GIF 之前统一转换和验证实际 GIF 内容，覆盖重试和原生分支。有效 GIF 会保留 GIF 扩展名，视频会转换为 GIF 后再导出，失败时返回错误。解析得到的动图默认选择 GIF。已有历史导出文件需要重新下载才能应用本次修复。

本轮验证包含 Windows 后端测试、桌面和窄屏浏览器检查、真实本地媒体批量下载、HTTP 范围查看，以及 Android GIF 的 FFmpeg 转换、MediaStore 导出、系统解码和应用图片解码。网页图片布局测试使用受控返回数据，未将其作为真实平台端到端验证。QQ、Telegram 和真实账号下载未在本轮验证。

构建命令沿用 Gradle 的 assembleRelease 和 windows/build_release.py --mode web。便携包在 windows/release/OmniDownloader_Web-1.7.51.zip，Android APK 在 release/1.7.51。替换本机服务时备份原程序及用户数据，核对任务、设置与会话。

最终验证为 Windows 102 项后端测试、Android 298 项 JVM 测试和 6 项模拟器 GIF 测试通过。首轮并行构建时，既有范围下载取消测试出现一次文件清理时序失败，完成构建后完整复测通过。GIF 测试确认文件内容、动画帧、系统解码与应用预览。独立 Web EXE 实际完成两条本地媒体下载及最近任务打开，替换后 58000 服务保留 3 条历史任务和既有配置、会话。ARM64 APK 已通过签名校验，未在 ARM64 真机执行本轮测试。
