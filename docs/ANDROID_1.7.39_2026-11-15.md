# Android 1.7.39：修复 Pixiv 画师主页原图误判

versionCode 98。修复画师主页读取到部分作品后，提示 `[MEDIA_ID_MISMATCH] 原图与作品页不一致`，无法继续解析的问题。

## 原因与修复

在用户提供的 `https://www.pixiv.net/users/59290023` 复现：作品 `144196490` 的官方 `pages` 响应使用 `144196490-8b2d018ecd2666ccd6e4f7beefc952d8_p0.png` 原图文件名。旧规则只接受 `144196490_p0.png`，将合法版本哈希误判为其他作品。

现在同时接受 `<作品ID>_p<页码>.<扩展名>` 和 `<作品ID>-<32位十六进制版本哈希>_p<页码>.<扩展名>`。原图链接保持接口原值，不拼接或猜测图片地址。继续核对画师归属、作品 ID、准确页码、页数、HTTPS、pximg.net 官方域名及 `/img-original/` 路径；错误作品、页码、缩略图和不可信来源仍会拒绝。错误信息补充作品 ID 与页码，便于定位后续异常。

现有逐作品检查点保持有效，可在当前会话点击继续解析；升级导致应用进程重启时，需重新填入画师主页解析。没有将真实身份错误吞掉或当成解析完成。

## 验证记录

- 修复前新增回归测试准确失败于官方版本哈希原图；修复后 269 项 JVM 测试通过，涵盖原图身份、错误哈希、其他作品/页码、缩略图及伪造来源拒绝。
- Android 在线测试使用该画师官方索引及生产解析入口，从第 39 个已完成作品的检查点继续，经 139、239 到 328 个作品全部完成，共 368 个图片/动图资源条目，旧结果保持不变。通过生产下载入口保存故障原图，解码尺寸为 2414×3152，与原图元数据一致。共用时 94.03 秒；没有下载整个画师图库，只下载受影响的原图。结果见交付目录 `qa/live-resume.json`。
- 正式包构建、Lint、原签名检查和 R8 包冒烟日志随交付保存。运行时、原生库与引擎资源不因本修复升级。
- 首次正式包冒烟被模拟器的 System UI 未响应弹窗挡住，未进入首页检查；保留失败日志，恢复系统界面后在独立测试安装上重新验证。

仅修改 Android。本次在线测试使用 Android 15 x86_64 模拟器及本机代理，不代表所有账号和网络均可访问相同作品。ARM64 正式包冒烟跳过原生执行，未在实体 ARM64 手机验证。未公开发布至 GitHub，未替换本机 Web、Windows 或 iOS。
