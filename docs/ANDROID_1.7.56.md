# Android 1.7.56 统一开屏退场

保留首次冷启动最短 500ms 开屏条件。Android 8 及以上统一执行应用控制的 400ms 整体淡出，退场期间首页保持最终位置、尺寸及不透明度。

## 行为

- Android 12+ 也注册开屏退出回调，接管应用可控制的系统退出阶段，避免沿用系统的主窗口上移退出。
- 开屏视图交给应用后，先在不透明遮罩下绘制首页最终布局，再开始淡出。遮罩透明度沿一个连续线性时间轴从 1 到 0，图标与背景作为整体消散。
- 系统移交开屏视图前阻止首页提前闪现，接收到遮罩后恢复首页。准备阶段构建临时图层并等待渲染提交，之后再启动计时；淡出期间只缓存开屏层，结束或中断时恢复原图层类型。
- 退场结束后移除遮罩，开放后台工作条件；再等待后续首页绘制，执行引擎预热与下一次开屏的主题同步。
- 状态恢复、同进程新 Activity、后台返回及用户切换主题均经过同一个调度入口。后台、销毁与取消路径清理等待回调，遮罩只移除一次。关闭系统动画时立即结束退场。
- 引擎仍通过原有互斥初始化入口按需工作。会话存储的早期 IO 准备保持现有实现。

`MainActivity` 的 `OmniStartup` 日志记录淡出开始、结束与退场后首页绘制的单调时钟时间，用于验证顺序。日志不包含链接或凭证。

应用版本为 1.7.56，versionCode 为 115。实现复用 `SplashFadeOut.kt` 和 `FirstDrawWork.kt`。

## 验证方法

仪器测试检查完整 400ms 淡出曲线、重复移除防护、取消、关闭动画、同进程重开、退出中切后台、重建与主题切换。

发行构建使用录屏中的首页标题区域与最终截图进行归一化图像匹配，跟踪实际屏幕位置，并检查多个半透明中间帧。此项用于发现窗口层面的移动，补充 View 的 translationY 检查。另通过启动阶段日志核对后台工作晚于退场结束。

当前测试设备为 Android 15 / API 35、x86_64 软件渲染模拟器。ARM64 真机和 Android 8–11 的实际系统分支仍需另行验证。

## 本轮结果

- 最终实现的 13 项仪器测试通过，日志 `.local/splash-unified-verified-tests.log`。覆盖连续透明度、400ms 配置、中断、取消、渲染提交回调、图层释放、同进程重开、状态恢复、主题及原有首页交互。
- 实际 R8 Release x86_64 APK 的四种配色均通过冷启动录屏检查。标题区域与底部导航分别跟踪，每个场景观察到的屏幕纵向偏移均为 0px（录制宽度 540px）。同时检查渐显强度未发生倒退。
- 每种场景捕获 16–18 个可辨识的半透明中间帧。实测从淡出开始到遮罩清理完成为 417–440ms，包含帧调度和清理开销；后续首页绘制标记晚于清理完成 13–15ms，随后才执行后台工作。
- 深浅色分别关闭三种系统动画缩放后冷启动通过，首页正常显示，退场直接收尾，最终 crash 日志为空。

记录位于 `.local/splash-unified/`，包括原始 MP4、截图、`*.motion.json`、阶段日志、`theme-validation.json` 和 `disabled-validation.json`。最终录屏检查输出在 `.local/splash-unified-recording-verified.log`。初次检查发现的首页闪现及中间帧不足已分别修复；原检查门槛保持不变并完成复测。

宿主 GPU 模式的模拟器在启动时以 -1073741819 退出，未能执行硬件 GPU 验证。软件渲染结果不构成真机帧率保证。

ARM64 发行构建成功，APK v2 签名有效，版本为 1.7.56（115），ABI 为 arm64-v8a，签名证书与 1.7.55 一致。输出在 `release/1.7.56/`，包括安装包、SHA256SUMS.txt 和从实际录屏截取的两秒 `splash-preview.mp4`。预览末尾延长首页静帧以便查看，动画过程未变速。
