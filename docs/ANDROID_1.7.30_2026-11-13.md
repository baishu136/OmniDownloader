# Android 1.7.30：抖音解析等待优化

仅 Android，versionCode 89，保留原签名及 ARM64 原生组件。

- 原生分享页取得目标视频信息后即显示下载选项，后续详情及网页补全异步更新选项；保留手选格式和下载模式，关闭选项后不会自动重开，不重复创建下载任务。自动下载及批量下载仍等待有界补全结束后选择可用最高规格。
- 同一请求使用 15 秒单调时钟工作预算，包括短链展开及解析互斥锁等待。短链展开最多 4 秒，分享页最多 3.5 秒，目标详情接口最多 1.2 秒，自动页面最多 8 秒，尺寸探测最多 1.5 秒；阶段共享截止时间，不逐项累加。WebView 的代理资源释放另有最多 2 秒的有限等待；这不是主线程阻塞情况下的硬实时保证。
- 分享页网络读取可取消，不再阻塞读取完整页面后才响应取消。网页脚本回调及排队也受超时控制；本次超时保留已有结果，用户取消和账号策略变更不会被转为成功。
- 先提取目标作品，再判断登录提示；“扫码登录”等可选弹窗不再直接阻断可播放作品。真实登录墙和验证码仍明确返回对应状态，不抓取推荐视频或验证码占位动画。
- 移除固定的 2.5/7 秒网页等待，完整规格稳定 600 毫秒即可结束。已有播放规格覆盖平台参考规格时，不因 720p 或未知备用源而继续等待网页。
- 尺寸检查优先验证最高候选源，已实测结果按作品、会话、网络和完整源 URL 缓存五分钟；有警告的可用解析结果短暂复用 20 秒，完整结果最多五分钟。登录、Cookie 及代理变更隔离缓存。未测量的尺寸不会标为已验证。
- 修复短链超时被误报为作品 ID 不匹配的问题。无法展开的短链及时报告网络错误，批量解析不重复展开同一失败短链。
- 实测发现旧分享播放接口 `/aweme/v1/playwm/` 会为样例追加约三秒片尾。仅对 `aweme.snssdk.com` 的已知无签名旧接口改用同一媒体 ID 的标准播放路径；保留所有原始查询参数及画质标签，不改写带签名、未知参数或其他 CDN 的 URL。不放宽成品时长校验，也不凭上传尺寸虚标播放分辨率。

## 验证

设备：Android 15 x86_64 专用模拟器，匿名会话，通过本机 HTTP 测试代理联网。页面耗时为本地 WebView 样例单次测量，不代表公网通用性能。

| 本地页面样例 | 旧实现 | 最终实现 |
| --- | --- | --- |
| 完整 720p 规格首次结果 | 7,431 ms | 1,265 ms |
| 延迟返回高清源 | 等待整轮结束 | 732 ms 显示 720p，2,660 ms 补入 1080p |
| 可选登录弹窗与目标视频并存 | 错报 AUTH_REQUIRED | 正常取得同一目标 |

211 项 JVM 单元测试、19 项 Android 设备回归通过。包含总体预算、排队、详情接口超时、取消、账号切换、真实登录墙/验证码、迟到画质合并、选择保留、探测缓存、完整下载字节不变，以及首页与批量下载回归。ARM64 R8 优化包启动、导航及资源冒烟 1 项通过；该冒烟跳过 ARM64 原生执行。Lint 为 0 errors、51 warnings。

最终真实分享链接 `pVm2K726QIc` 无手动浏览器操作：1,822 ms 显示候选源，11,786 ms 完成补全尝试，完整下载 4,429,153 字节，实测 960×720、16,467 ms、有音轨；高清补全超时如实保留警告，没有证明与上传原片同画质。

原作品 `7699370307513319141` 的匿名第一方响应回放下载验证：5,269,795 字节，720×1280、12,446 ms、有音轨，时长校验通过；这是回放响应验证，不算实时自动解析成功。相同作品最终实时请求仍需浏览器协助（8,826 ms）；另一个分享链接最终也需协助（11,781 ms），均不计下载成功。更早请求中该分享链接曾返回图文数据，视频解析按 NO_MEDIA 交由现有图文路由处理。

接口思路参考：[第一方开源解析实现](https://github.com/ldsoy/douyin-video-parser)。本次旧接口判断及修复以真实响应、FFmpeg 检查和 Android 完整下载校验为依据。

## 调试记录

- 症状：可播放目标被可选登录弹窗阻断，完整 720p 页面固定等待约七秒，多阶段超时叠加；缩短探测预算后暴露旧播放接口的额外片尾。
- 根因：登录提示先于目标提取、固定等待、重复尺寸探测、未统一排队/脚本回调预算，以及旧分享接口片尾与作品时长不一致。
- 修复：先提供目标信息，再有界补全；有效规格驱动结束；会话隔离缓存与可取消 HTTP；已验证旧接口改用同一媒体的标准播放路径。
- 证据：旧实现两项回归失败，最终 211 项单元及 19 项设备回归通过，原作品响应回放完整下载和另一真实链接完整下载通过，优化包冒烟通过。
- 状态：DONE_WITH_CONCERNS。平台访问校验和高画质可用性仍可能限制个别作品；未进行 ARM64 实体手机验收。
