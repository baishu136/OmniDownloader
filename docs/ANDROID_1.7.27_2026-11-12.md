# Android 1.7.27

仅 Android，versionCode 86。批量输入框右侧使用与首页一致的 19dp 粘贴/清空图标和本地化无障碍标签：空输入显示粘贴，有内容显示清空。清空仅处理当前模式的输入，不删除已添加链接或已有下载任务。

输入框粘贴图标及“粘贴剪贴板”按钮共用一次操作：读取剪贴板、填入当前模式、识别并添加到链接列表。成功后按原添加流程清空当前输入；识别失败、单条模式收到多条链接时保留内容和错误提示。空剪贴板、超长文本明确提示，不静默截断。保留原去重、容量限制和手动添加按钮。粘贴不会直接开始解析或下载。

Android 15 x86_64 模拟器验证按钮粘贴、图标粘贴、重复去重、清空保留列表、单条模式拒绝多链接、智能模式多链接添加、无效输入保留和未自动创建下载任务。最终 Release 构建、Lint、优化包检查及签名日志见 qa。原 ARM64 载荷与签名保持；未完成 ARM64 真机验收。本轮未发布 GitHub Release。
